## The joke

> I tried to make the bed laugh — it said it was already in stitches.

67 characters, one line, no throat-clearing. The punchline is a double pun that
lands on the very last word: "in stitches" means both laughing uncontrollably
and the literal stitching of bedding, so the setup ("make the bed laugh") and
the twist are the same sentence, and the groan arrives before the listener has
time to brace for it.
